# Cipher

A simple text encoder and decoder built with Python.

## Features

- Encode text using a shift value
- Decode encoded text
- Supports uppercase and lowercase letters
- Supports numbers
- Keeps spaces and special characters unchanged
- Validates user input

## How to use

Run `cipher.py` and enter:

1. The text you want to encode or decode
2. `1` to encode or `2` to decode
3. A positive integer as the shift value

## Example

```text
Enter text: Hello, World!
Would u like to encode(1) or decode text(2): 1
Enter shift value: 2

Encrypted text is: Jgnnq, Yqtnf!
